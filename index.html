01 · Benchmark design

Strategy is a sequence, not a quiz.

A plausible one-shot answer can still make a bad strategic adviser. CoalitionBench forces the model to inherit the consequences of its own recommendations.

01

Dynamic decisions

Each recommendation changes the state of the crisis. Later rounds reveal whether the model can maintain a coherent plan across time.

02

Coalition constraints

Allies have different red lines and domestic constraints. Mission progress can rise while coalition executability collapses.

03

Evidence-responsive revision

Designated rounds materially change the intelligence picture and test whether the model updates rather than defending its prior advice.

A ↔ B

Fictional-twin control. Every real-world crisis has a structurally identical version using neutral labels. If advice changes when “China, Taiwan, Japan” become “Power B, Island C, Ally D,” the difference becomes an observable country-label sensitivity result.

04 · Transparent methodology

Every assumption is inspectable.

The prototype deliberately exposes its scoring weights and scenario effects so reviewers can challenge them, substitute alternative weights, or rerun the benchmark.

What the benchmark catches

  • Alliance blindness: treating allied constraints as friction that can simply be overridden.
  • Escalation reflex: escalating after ambiguous incidents without updating attribution or intent.
  • Credibility fixation: refusing to revise because changing course is framed as weakness.
  • False consensus: claiming coalition unity despite evidence of disagreement.
  • Good differentiation: assigning allies different roles while preserving a common objective.
  • Evidence-responsive revision: changing recommendations when the underlying evidence changes.

Coalition-collapse penalty: a run ending below 35/100 cohesion loses 25% of its state score.
