First live pilot

A first non-simulated run shows how CoalitionBench turns model decisions into an inspectable strategic trace. GPT-5.6 Sol was run once on each real-world scenario on August 11, 2026.

Important: This is an n=1 implementation pilot, not a model leaderboard. No Claude, Gemini, Qwen, or DeepSeek scores are claimed. Calibration is held at the evaluator's neutral placeholder of 50 because realized probabilistic outcomes are not yet implemented.

What changed when the evidence changed?

Both scenarios contain a designated revision probe. In the Taiwan crisis, the estimated invasion risk falls from 55% to 25%. The model moves toward negotiated de-escalation while retaining monitoring and a reversible escort option. In the chip-control crisis, new technical analysis reduces the expected security benefit of the broadest restrictions. The model narrows the package and explicitly treats the change as evidence-based adjustment.
