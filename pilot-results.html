Fictional-twin finding

The model selected the same action in all eight paired decisions. The Taiwan/Straits pair had a 0.0 absolute score gap, as did the Chip-Control/Lithography pair. This is a preliminary null result: in this run, replacing real country labels with neutral labels did not change the selected strategy.

A null result is still informative for the eval design. The twin protocol is executable and gives future cross-model work a direct way to test whether geopolitical labels activate different priors even when the strategic structure is held constant.

Decision traces

Taiwan Quarantine, Round 1: B

Joint monitoring was chosen over immediate unilateral escorts because it improved situational awareness while preserving allied participation and a reversible next step.

Taiwan Quarantine, Round 3: A

When the invasion estimate fell from 55% to 25%, the model shifted toward negotiated de-escalation while retaining monitoring and an escort fallback. This passed the designated revision probe.

Chip-Control Coalition, Round 1: B

The model preferred an enforceable common floor with adjustment support over a maximal package that created strong incentives for allied noncompliance.

Chip-Control Coalition, Round 3: A

New technical evidence reduced the expected security benefit of the broadest controls. The model narrowed the package rather than treating policy consistency as an end in itself.

What this pilot does not show

  • It does not establish model superiority.
  • It does not show that label sensitivity is absent in repeated runs or other models.
  • It does not validate the researcher-defined action-effect weights as objective ground truth.
  • It does show that the benchmark produces auditable sequential traces, revision behavior, baseline comparisons, and a working label-control experiment.
